# Roar of the Lion

## This project presents a systematic replication and empirical verification of Lion (EvoLved Sign Momentum), a novel first-order optimization algorithm discovered via symbolic program search by Chen et al. (2023)1more_horiz. Unlike traditional adaptive optimizers like AdamW that track both first and second moments of gradients, Lion tracks only momentum, making it significantly more memory-efficient14. Furthermore, Lion calculates updates using an element-wise sign operation to maintain uniform update magnitudes across all dimensions, which acts as a regularizer to guide models toward flatter minima and better generalization1more_horiz.Over a structured timeline, we implement the Lion optimizer from scratch in PyTorch using the mathematically simplified algorithm discovered via evolution6more_horiz. We benchmark its performance against standard AdamW on image classification tasks using datasets like CIFAR-100 to replicate the paper's core claims. Specifically, we investigate the unique hyperparameter dynamics of Lion, verifying that it requires a 3–10x smaller learning rate and a 3–10x larger decoupled weight decay ($\lambda$) than AdamW to maintain equivalent effective weight decay strength910. Additionally, we profile and analyze: (1) computational efficiency, aiming to reproduce the reported 2–15% step runtime speedup and reduced memory footprint4; (2) batch-size sensitivity, testing the paper's finding that Lion’s performance improvements scale exceptionally well with larger training batch sizes411; and (3) loss geometry, evaluating the flatness of the converged loss landscape under Gaussian perturbations to verify that Lion consistently converges to smoother regions
